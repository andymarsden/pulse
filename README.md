# Pitchside

A SvelteKit football scores dashboard covering the Premier League, La Liga, Serie A, Bundesliga and Ligue 1. Scores come from ESPN's public scoreboard feed. If the feed is unavailable, the dashboard clearly labels its example scores; a partial feed failure is also shown.

```sh
npm install
npm run dev
```

Use `npm run check` for Svelte and TypeScript diagnostics and `npm run build` for a production build. Deployment may require a SvelteKit adapter for your hosting platform.
